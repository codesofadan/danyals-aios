## Compliance flags surfaced by this harvest (for the auditor)
- Protection plan, NOT insurance -> SS-1: never write insurance/coverage/policy/premium for it.
- Humidity IS controlled -> SS-5: the moisture/mildew copy is permitted, with the real 55-80F range stated.
- Live PMS inventory -> SS-CV1: a real "X units left" is permissible; still show the real number, never hard-code.
- Standard month-to-month, no rate guarantee -> SS-8: no "rate locked" claim.
- ADA not verified -> SS-12: no "ADA compliant / wheelchair accessible" claim.
- TX lien statute (Property Code ch. 59) -> SS-11: any auction/lien timeline traces here (14-day notice, 2 weekly publications).
- $25 admin fee -> SS-6: disclosed in-line with "first month free."
