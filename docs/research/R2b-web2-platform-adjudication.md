## D. Summary

- **Rows adjudicated: 70** (all catalogue rows with no `terms_checked_on`). **Tier changes recommended: 1 firm + 1 owner-optional.** **68 stay do_not_use** — but now with a terms position, a source, and a date each, instead of an unexamined default.
  - **Webflow → per_client (conditional)** — the single most valuable unlock: first-party Data API, free self-serve signup, client-named `*.webflow.io` subdomain that IS indexed on the free tier, and no terms clause against programmatic posting. Caveats to record: 2-page/50-item free cap, [UNVERIFIED] signup CAPTCHA and link `rel` (measure via R2-16).
  - **rentry.co → house (owner decision)** — passes every Tier-B criterion exactly as Telegra.ph does (anonymous, article-shaped, permanent), but on an *unofficial* API; adopt only if the owner accepts that, with a low cap.
- **Re-affirm and finally seed** the §3.2 verdicts 0103 missed: **Ghost, Dreamwidth, Bluesky** (do_not_use), so their `terms_checked_on` stops being NULL.
- **The four chosen platforms are unchanged**, and one long-standing caveat retires: **WordPress.com no longer 403s automated fetch** — both pages read directly today, quotes confirmed, guidelines "last reviewed 2026-08-12". Telegra.ph could not be reached from this sandbox: [UNVERIFIED today], settle with a client smoke test.
- **Operational red flags found while adjudicating** (act on these regardless of tiers):
  1. **Mataroa holds a live house credential, and its operator manually deletes SEO blogs on sight** (54% of all blogs purged). Retire that credential; any placement there is a dead man walking.
  2. **Micro.blog is paid-only ($5/mo+)** — its live house credential is a shared paid account; retire or convert.
  3. **Warpcast is now "Farcaster" and was acquired by Neynar (2026-01)** — catalogue name, URLs and notes are stale.
  4. **Wix's "no write API" note is stale** — a Draft Posts write API now exists for owned sites.
  5. **LiveJournal's 2026-03-18 User Agreement requires an "Administration permit" for scripts/bots** — the adapter as used would breach terms on contact.
- **Staleness discipline (R2 §8 risk 5):** every verdict above should be seeded with `terms_checked_on = 2026-09-02` and enters the same 90-day Policy Radar staleness window as the 0103 set.
