- `0139_seed_grid_automation.sql` — the weekly sweep, seeded paused (later enabled).

  `app/admin/grid/`, nav entry.
- **61 tests.** Non-vacuity proven by re-injecting the error→absent defect.

**The load-bearing design:** a grid point is one of three states — `ranked`,
`absent` (measured, not in the pack), `error` (**never measured**). CHECK constraints
make blurring them impossible, and every ratio divides by MEASURED points. Without
that, a rate-limited afternoon renders as a client's service area collapsing,
permanently, in an append-only table.

**Retired:** `danyals-audit-system/.../geo_grid.py` was orphaned AND wrong — it sent
`location="lat,lng"` to a parameter that wants a place name, which returns an
unlocalised SERP for every point: a perfectly smooth, entirely fictional heat map.

### 3. Design replicator — four defects, found against `hudamoji.pk`
| Defect | Fix |
|---|---|
| Content root fell back to `document.body`, so the chrome guard rejected every header/footer it contained — a **torso** replica, blaming the source | root prefers the tallest real body child; guard rejects only a candidate that IS or WRAPS the root; double-walking prevented by `SKIP_EL` |
| Selector list blind to `<nav>` / `[role=banner]` | widened, with position sanity so a mid-page nav cannot be adopted |
| **`to_hex` could not read `oklch()`/`lab()`** — Tailwind v4, i.e. most sites since ~2024. Every brand colour parsed as nothing; only literal whites survived | new `app/services/color_spaces.py` — CSS Color 4 reference transforms |
| `"ink"` matched `--color-pink-300` as a substring | whole-segment token matching |

Measured on that site: palette **2 roles (both `#ffffff`, "ungrounded") → 7 roles,
grounded**; header + footer now replicate; 17.8s → 12.1s.

`color_spaces.py` is verified **without trusting any colour table**: `lab()` and
`oklch()` are independent code paths and converge on the same byte. One test was
deleted because its reference value was one I had derived myself — that tests my
arithmetic, not the transform.
